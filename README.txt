ШКОЛЬНЫЙ УЧЁТ — CLOUDFLARE WORKER + D1

Эта версия заменяет локальную localStorage-базу на Cloudflare D1.
После настройки данные будут общими для компьютеров, которые открывают этот Worker.

ВАЖНО
1. Старая версия сайта была только Static Assets. Поэтому D1 нельзя было привязать.
2. Эта версия уже содержит Worker-код (worker.js) и папку public/ со статическими файлами.
3. Существующую D1-базу создавать заново НЕ нужно.

СТРУКТУРА
worker.js             сервер/API + работа с D1
wrangler.jsonc        конфигурация Worker + Static Assets
schema.sql            схема D1 (Worker также создаёт таблицы автоматически)
public/index.html     сайт
public/style.css      стили
public/app.js         интерфейс и запросы к API

РЕКОМЕНДУЕМЫЙ СПОСОБ ДЕПЛОЯ
Cloudflare сейчас рекомендует Workers Static Assets для full-stack приложений.

1. Установить Node.js, если его нет.
2. В папке этого проекта выполнить:
   npx wrangler login
   npx wrangler deploy

3. После deploy открыть Cloudflare:
   Workers & Pages → ваш Worker → Settings/Bindings.

4. Добавить D1 Database binding:
   Variable name: DB
   Database: выбрать уже созданную вами D1-базу.

5. Добавить секрет для очистки базы:
   Settings → Variables and Secrets → Add secret
   Name: CLEAR_DB_PASSWORD
   Value: придумайте пароль администратора.

6. Открыть сайт и проверить:
   /api/health
   Должен вернуться JSON с ok=true и database=D1.

7. Открыть сам сайт. При первом обращении Worker автоматически создаст таблицы,
   если их ещё нет.

ПЕРЕНОС СТАРЫХ ДАННЫХ
Старая версия хранила данные только в localStorage конкретного компьютера.
Новая версия не может автоматически увидеть этот localStorage.
Если у вас есть JSON-резервная копия старой базы:
   Резервная копия → Загрузить JSON
и данные будут загружены в D1.

БЕЗОПАСНОСТЬ
В базе находятся ИИН учащихся. Не делайте такую базу общедоступной без защиты.
Рекомендуется дополнительно закрыть Worker через Cloudflare Access и разрешить вход
только уполномоченным сотрудникам школы.

ВАЖНО ПРО ПАРОЛЬ
Пароль CLEAR_DB_PASSWORD хранится как Secret на стороне Worker и не находится в app.js.
Это безопаснее, чем пароль в старой клиентской версии.

ЕСЛИ CLOUDFARE ПРОСИТ DATABASE ID
Этот пакет специально не содержит ID D1: привязка DB делается в Cloudflare Dashboard.
Поэтому один и тот же ZIP можно использовать с вашей уже созданной базой.
